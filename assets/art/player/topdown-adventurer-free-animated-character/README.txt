TOP-DOWN ADVENTURER (FREE ANIMATED CHARACTER)

A free top-down RPG character - hooded traveler with a backpack and
sword, seen from a classic top-down angle. Idle poses and a full walk
cycle in all 8 directions, ready to drop into any top-down or isometric
project (pairs well with the Isometric Fantasy Town Kit / Hex Kingdom
Tileset, but works with any top-down game).

WHAT'S IN THE BOX

png_204/        64 files: 8 idle poses + 8 directions x 7-frame walk cycle
png_204_x4/     the same, upscaled 4x nearest-neighbor
atlas/          one sprite sheet + JSON coordinates
preview/        promo sheets + an animated walk-cycle GIF

Every file is a square transparent PNG with the background fully cut,
bottom-aligned so feet line up consistently across every direction.

WHAT'S INSIDE

8 directions: south, south-east, east, north-east, north, north-west,
west, south-west - idle pose + 7-frame walk cycle each.
